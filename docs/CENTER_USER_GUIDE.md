## 🔐 การลงทะเบียนและเข้าสู่ระบบ

### 1. การลงทะเบียนบัญชีใหม่
1. คลิกปุ่ม "ลงทะเบียน" ที่หน้าแรก
2. เลือกบทบาท:
   - **เจ้าของศูนย์ความงาม**: สำหรับเจ้าของธุรกิจศูนย์ความงาม
   - **ผู้เชี่ยวชาญ**: สำหรับแพทย์ผิวหนังหรือผู้เชี่ยวชาญด้านความงาม
   - **พนักงานขาย**: สำหรับทีมขาย
   - **ลูกค้า**: สำหรับผู้มารับบริการ
3. กรอกข้อมูลส่วนตัวและข้อมูลศูนย์ความงาม (ถ้ามี)
4. ยืนยันอีเมล
5. ตั้งรหัสผ่านที่ปลอดภัย

### 2. การเข้าสู่ระบบ
1. คลิก "เข้าสู่ระบบ"
2. ป้อนอีเมลและรหัสผ่าน
3. ระบบจะ redirect ไปยัง dashboard ตามบทบาท

### 🤖 การวิเคราะห์ผิวหน้าด้วย AI

- ประเมินปัญหาผิวหน้า (ริ้วรอย, รอยดำ, สิว, รูขุมขน)
- ให้คำแนะนำการดูแลผิวแบบเฉพาะบุคคล
- บันทึกประวัติการวิเคราะห์

### 👥 การจัดการลูกค้า
- บันทึกข้อมูลลูกค้า
- ติดตามประวัติการรับบริการ
- จัดการนัดหมาย
- ส่งการแจ้งเตือนอัตโนมัติ

### 📊 รายงานและสถิติ
- สถิติลูกค้าใหม่รายวัน/รายเดือน
- รายงานยอดขาย
- ประสิทธิภาพการให้บริการ
- ข้อมูลยอดนิยมของบริการ

### 💼 การจัดการศูนย์ความงาม
- จัดการข้อมูลพนักงาน
- ตั้งค่าบริการและราคา
- จัดการตารางเวลา
- สิทธิ์การเข้าถึงข้อมูลตามบทบาท

## 🔬 การวิเคราะห์ผิวหน้าด้วย AI

### ขั้นตอนการวิเคราะห์
1. **เข้าสู่ระบบ** และไปที่เมนู "วิเคราะห์ผิวหน้า"
2. **เลือกลูกค้า** จากรายการ หรือสร้างใหม่
3. **อัปโหลดรูปภาพ**:
   - ใช้รูปที่ชัดเจน สว่างพอ
   - ถ่ายในที่สว่าง ไม่มีเงา
   - หน้าตรง ไม่มีอุปกรณ์บดบัง
4. **รอผลการวิเคราะห์** (ประมาณ 30-60 วินาที)
5. **ดูผลลัพธ์**:
   - คะแนนสุขภาพผิวโดยรวม
   - รายละเอียดปัญหาผิว
   - คำแนะนำการดูแล
   - ผลิตภัณฑ์ที่แนะนำ

### เคล็ดลับสำหรับรูปภาพที่ดี
- ถ่ายในที่มีแสงธรรมชาติ
- หลีกเลี่ยงแสงแดดจ้า
- ทำความสะอาดหน้าก่อนถ่าย
- ถ่ายให้ใบหน้าเต็ม
- หลีกเลี่ยงการใช้ฟิลเตอร์

## 👥 การจัดการข้อมูลลูกค้า

### การเพิ่มลูกค้าใหม่
1. ไปที่เมนู "ลูกค้า"
2. คลิก "เพิ่มลูกค้าใหม่"
3. กรอกข้อมูล:
   - ชื่อ-นามสกุล
   - ข้อมูลติดต่อ
   - ประวัติการแพ้
   - ข้อมูลสำคัญอื่นๆ
4. บันทึกข้อมูล

### การดูประวัติลูกค้า
- คลิกที่ชื่อลูกค้า
- ดูประวัติการวิเคราะห์ผิว
- ดูประวัติการรับบริการ
- ดูข้อมูลการติดต่อ

## ⚠️ ข้อควรระวังและคำแนะนำ

### ความปลอดภัยข้อมูล
- ระบบมีการเข้ารหัสข้อมูลส่วนบุคคล
- ใช้ Row Level Security (RLS) ป้องกันการเข้าถึงข้ามศูนย์ความงาม
- สำรองข้อมูลอัตโนมัติทุกวัน

### การปฏิบัติตาม PDPA
- ไม่เปิดเผยข้อมูลลูกค้า
- ขอความยินยอมก่อนเก็บข้อมูล
- ลูกค้าสามารถขอลบข้อมูลได้

### ข้อแนะนำ
- อัปเดตข้อมูลลูกค้าสม่ำเสมอ
- ตรวจสอบความถูกต้องของข้อมูลก่อนวิเคราะห์
- ใช้ผล AI เป็นข้อมูลประกอบการตัดสินใจเท่านั้น
