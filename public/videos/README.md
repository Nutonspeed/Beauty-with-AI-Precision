## How to Download:
1. Go to any site above
2. Search for "beauty technology" or "facial treatment"
3. Download in 1080p MP4 format
4. Save as `hero-demo.mp4` in this folder
5. Also save a screenshot as `hero-poster.jpg` in `/public/images/`

## Video Requirements:
- Format: MP4 (H.264)
- Resolution: 1920x1080 preferred
- Duration: 10-30 seconds
- File size: Under 10MB ideal

## Quick Download Commands:

### Using curl (if you have direct URL):
```bash
curl -o hero-demo.mp4 "VIDEO_URL_HERE"
```

### Using youtube-dl for YouTube:
```bash
youtube-dl -f mp4 -o hero-demo.mp4 "YOUTUBE_URL"
```
